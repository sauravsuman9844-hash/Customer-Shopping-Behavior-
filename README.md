# Customer-Shopping-Behavior

# 🛍 Customer Shopping Behavior Analysis & Dashboard (Python, SQL & Power BI)

## 📌 Project Overview
This project analyzes customer shopping behavior using transactional data to identify
purchase patterns, revenue trends, and customer segments. Python and SQL are used for
data cleaning, exploratory data analysis (EDA), and data storage, while Power BI is used
to create interactive dashboards for business insights.

---

## 🛠 Tools & Technologies
- Python (Pandas)
- SQL (Data querying and analysis)
- PostgreSQL (Database storage)
- Power BI (Interactive dashboards & visualization)

---

## 📂 Dataset Description
- Contains **3,900+ customer transaction records**
- Includes customer purchase details, product categories, revenue, and transaction dates
- Raw data cleaned and transformed using Python before loading into PostgreSQL

---

## 🔍 Analysis Performed
- Data cleaning and preprocessing using Python
- Exploratory Data Analysis (EDA) to understand customer behavior and trends
- Revenue analysis by product category and time period
- Customer segmentation based on shopping frequency and spending behavior
- Stored processed datasets in PostgreSQL for structured querying

---

## 📊 Power BI Dashboard
- Key performance indicators (KPIs) for revenue and transactions
- Interactive slicers for product category and date range
- Visual analysis of customer segments and purchasing trends
- Trend charts to support data-driven business decisions

---

## 📈 Key Insights
- Identified high-value customer segments based on spending patterns
- Certain product categories contributed significantly to overall revenue
- Seasonal trends observed in customer purchasing behavior

---

## 🚀 Conclusion
This project demonstrates end-to-end data analysis by combining Python, SQL, and Power BI
to transform raw transactional data into actionable business insights.
